# 悬浮球表情图

把表情图放进这个文件夹，悬浮球会自动改用图片；没有任何图片时使用内置的 SVG 表情脸。
改完图片后重启应用生效。

## 规格

- 文件名：`<表情>.png`（也支持 `.webp`、`.gif`），全小写英文。
- 尺寸：正方形，512×512（最低 256×256）。每张尽量不超过 300 KB。
- **球的圆要铺满整张图，边缘不要描边。** 程序会把图放大约 7% 并朝鼠标方向平移、倾斜，再按圆形裁切；描边或贴边的内容会被切掉或出现缝隙。
- 重要内容放在中间约 70% 的区域；球上只有 72 像素，线条要粗、对比要强。
- 所有表情用同一画布、同一视角、同一画风，脸的位置和大小保持一致。
- 圆以外的四个角是透明还是填色都可以，它们会被裁掉。

## 表情清单

| 文件名 | 什么时候出现 | 缺图时的替代 |
|---|---|---|
| `idle` | 平时（**必须有**，有它才会启用图片模式，也是所有缺图的最终替代） | — |
| `blink` | 随机眨眼，只替换 idle：画面与 idle 完全相同，仅眼睛闭上 | 不眨眼 |
| `thinking` | 模型在思考 | idle |
| `working` | Agent 正在操作你的电脑 | thinking → idle |
| `happy` | 任务完成 | idle |
| `error` | 出错或断连 | idle |
| `hello` | 面板展开，球在听你说话 | idle |
| `curious` | Agent 向你提问或需要授权 | surprised → idle |
| `surprised` | 鼠标刚移上来 | idle |
| `sleepy` | 很久没人理 | blink → idle |
| `shy` | 被你戳一下 | happy → idle |
| `dizzy` | 被你拖动 | surprised → idle |
| `celebrate` | 下班提醒 | happy → idle |
| `writing` | 写日报提醒 | working → thinking → idle |

## 动作

呼吸、跳动、歪头、点头、晃动、朝鼠标倾斜、表情切换时的淡入淡出，都由程序加，图片只需要静态的一张。
